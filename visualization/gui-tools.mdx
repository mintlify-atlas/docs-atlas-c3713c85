The GUI module provides sophisticated Qt-based graphical interfaces for interactive neuroscience data analysis and visualization.

## Overview

pyPhoPlaceCellAnalysis offers extensive GUI tools built on **PyQt** and **pyqtgraph**, enabling:

- Interactive data exploration windows
- Dockable widget layouts
- Time-synchronized multi-panel displays
- File browser dialogs
- Custom control widgets
- Flowchart-based computation pipelines

### Time-Synchronized Plotters

Create synchronized multi-panel displays that update together:

```python
from pyphoplacecellanalysis.Pho2D.PyQtPlots.TimeSynchronizedPlotters.TimeSynchronizedPlotterBase import (
    TimeSynchronizedPlotterBase
)

class CustomTimeSyncPlotter(TimeSynchronizedPlotterBase):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        
    def update_time_window(self, new_start_time, new_end_time):
        """Called when time window changes"""
        # Update all plots to show data in new time range
        self.update_plots()
        
    def on_window_changed(self, window_start, window_end):
        """Handle window change events"""
        self.update_time_window(window_start, window_end)

# Create synchronized plotter
plotter = CustomTimeSyncPlotter(
    curr_active_pipeline.sess,
    data_manager=data_manager
)
```

## Best Practices

<AccordionGroup>
  <Accordion title="Window Management">
    - Use `PhoDockAreaContainingWindow` for complex layouts
    - Keep references to windows to prevent garbage collection
    - Call `window.show()` explicitly to display
    - Use `app.exec_()` to start the Qt event loop
  </Accordion>
  
  <Accordion title="Signal/Slot Connections">
    - Use Qt signals for event-driven updates
    - Disconnect signals when widgets are destroyed
    - Use lambda functions carefully (can cause memory leaks)
    - Keep strong references to callback objects
  </Accordion>
  
  <Accordion title="Performance">
    - Batch GUI updates to reduce redraws
    - Use `setUpdatesEnabled(False)` during bulk changes
    - Defer heavy computations to background threads
    - Cache rendered content when possible
  </Accordion>
  
  <Accordion title="Layout">
    - Use docking for flexible user layouts
    - Provide sensible default arrangements
    - Save/restore window geometry and state
    - Support both vertical and horizontal layouts
  </Accordion>
</AccordionGroup>

<Note>
  Qt applications require an event loop. In Jupyter, use `%gui qt` magic command. In scripts, call `app.exec_()` to start the loop.
</Note>

## Common Patterns

### Creating a Basic Qt Application

```python
import pyphoplacecellanalysis.External.pyqtgraph as pg
from pyphoplacecellanalysis.External.pyqtgraph.Qt import QtWidgets

# Create application
app = pg.mkQApp("My Neural Analysis")

# Create main window
main_window = QtWidgets.QMainWindow()

central_widget = pg.GraphicsLayoutWidget()

```

### Updating Plots Dynamically

```python
from pyphoplacecellanalysis.External.pyqtgraph.Qt import QtCore

class LivePlotter:
    def __init__(self):
        self.plot_widget = pg.PlotWidget()
        self.plot_item = self.plot_widget.plot()
        self.timer = QtCore.QTimer()
        self.timer.timeout.connect(self.update)
        self.timer.start(100)  # Update every 100ms
        
    def update(self):
        # Get new data
        new_data = get_latest_data()
        # Update plot
        self.plot_item.setData(new_data)
```

<Warning>
  Always keep references to Qt objects while they're in use. Python garbage collection may delete objects that Qt still references, causing crashes.
</Warning>
