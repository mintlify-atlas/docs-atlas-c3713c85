## Best Practices

<AccordionGroup>
  <Accordion title="IPyWidgets">
    - Use `Output` widgets to capture print statements
    - Clear output before updating: `output.clear_output()`
    - Keep widget references to prevent garbage collection
    - Use `display()` explicitly in functions
    - Combine widgets in VBox/HBox for layouts
  </Accordion>
  
  <Accordion title="Napari">
    - Set axis labels for clarity: `viewer.dims.axis_labels`
    - Enable grid for multi-layer comparison
    - Use appropriate colormaps for different data types
    - Connect slider events for synchronized updates
    - Export frames with consistent naming schemes
  </Accordion>
  
  <Accordion title="Performance">
    - Use appropriate data types (float32 vs float64)
    - Downsample large datasets for interactive viewing
    - Defer heavy computations until needed
    - Use generators for large sequences
    - Cache computed results
  </Accordion>
  
  <Accordion title="User Experience">
    - Provide clear widget labels and descriptions
    - Add progress indicators for long operations
    - Display helpful text overlays
    - Enable keyboard shortcuts in Napari
    - Save/restore viewer state
  </Accordion>
</AccordionGroup>

<Note>
  Napari viewers automatically handle multi-dimensional data. The slider along the bottom navigates through the first dimension, while additional sliders appear for higher dimensions.
</Note>

<Warning>
  When exporting image sequences, ensure the output directory exists and has write permissions. Large exports can consume significant disk space.
</Warning>

## Common Patterns

### Progress Indicators

```python
import ipywidgets as widgets
from IPython.display import display

progress = widgets.IntProgress(
    value=0,
    min=0,
    max=100,
    description='Processing:',
    bar_style='info'
)

status_label = widgets.Label(value='Starting...')

display(widgets.VBox([progress, status_label]))

# Update during processing
for i in range(100):
    progress.value = i
    status_label.value = f'Processing item {i}'
    # Do work

status_label.value = 'Complete!'
progress.bar_style = 'success'
```
