pyPhoPlaceCellAnalysis provides comprehensive 2D plotting capabilities through three primary backends: **PyQtGraph** (real-time, interactive), **Matplotlib** (publication-quality), and **Plotly** (web-interactive).

## PyQtGraph Plotting

PyQtGraph provides high-performance interactive plotting for real-time data exploration.

### Place Field Visualization

Display all place fields in a grid layout with interactive controls:

```python
from pyphoplacecellanalysis.Pho2D.PyQtPlots.plot_placefields import (
    display_all_pf_2D_pyqtgraph_binned_image_rendering
)

# Configure display
figure_format_config = {
    'color_map': 'viridis',
    'color_bar_mode': None,
    'drop_below_threshold': 0.0000001,
    'scrollability_mode': LayoutScrollability.SCROLLABLE,
    'brev_mode': PlotStringBrevityModeEnum.CONCISE
}

# Render place fields
out_fig = display_all_pf_2D_pyqtgraph_binned_image_rendering(
    active_pf_2D,
    figure_format_config,
    debug_print=True
)
```

### Image Array Plotting

Plot arrays of images (e.g., tuning curves):

```python
from pyphoplacecellanalysis.Pho2D.PyQtPlots.plot_placefields import pyqtplot_plot_image_array

# Get tuning curves
images = active_decoder.ratemap.normalized_tuning_curves  # (43, 63, 63)
occupancy = active_decoder.ratemap.occupancy

# Plot image array
app, win, root_widget, plot_array, img_item_array, other_components = \
    pyqtplot_plot_image_array(
        active_decoder.xbin,
        active_decoder.ybin,
        images,
        occupancy,
        max_num_columns=5,
        drop_below_threshold=0.0000001
```

```python

fig, axes = plt.subplots(2, 2, figsize=(12, 10))
```

### Raster Plots

Create spike raster plots with custom colormaps:

```python
from pyphoplacecellanalysis.PhoPositionalData.plot_data import (
    plot_eventplot_raster_plot,
    generate_colormap
)
import matplotlib.pyplot as plt

# Generate colors for neurons
num_cells = len(active_spike_list)
cmap = generate_colormap(number_of_distinct_colors=num_cells)

# Create color codes
color_codes = [cmap(i) for i in range(num_cells)]

# Plot raster
plt.eventplot(active_spike_list, color=color_codes)
plt.title('Spike Raster Plot')
plt.xlabel('Time (s)')
plt.ylabel('Neuron')
```

## Best Practices

<AccordionGroup>
  <Accordion title="Choose the Right Backend">
    - **PyQtGraph**: Large datasets, real-time updates, interactive exploration
    - **Matplotlib**: Publication figures, static plots, precise control
    - **Plotly**: Web sharing, hover interactions, 3D surface plots
  </Accordion>
  
  <Accordion title="Performance Optimization">
    - Use `drop_below_threshold` to filter low-occupancy bins
    - Enable scrollability for many subplots
    - Pre-compute normalized values
    - Use appropriate data types (float32 vs float64)
  </Accordion>
  
  <Accordion title="Color Selection">
    - Use `generate_colormap()` for neuron identification
    - Choose perceptually uniform colormaps (viridis, plasma)
    - Consider colorblind-friendly palettes
  </Accordion>
</AccordionGroup>
