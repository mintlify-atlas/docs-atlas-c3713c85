The Pho3D module provides powerful 3D visualization capabilities using **PyVista**, enabling interactive spatial analysis of neural activity.

## Overview

PyVista integration allows you to:
- Render 3D spatial trajectories
- Visualize spike positions in 3D space
- Create interactive arena environments
- Display dynamic lighting effects for spike events
- Build custom GUI controls for 3D scenes

## Arena Visualization

Create the experimental arena environment as a 3D mesh.

### Flat Arena with Extrusion

```python
from pyphoplacecellanalysis.Pho3D.PyVista.spikeAndPositions import perform_plot_flat_arena
import pyvista as pv

# Create plotter
p = pv.Plotter()

# Get position data
x = position_df['x'].values
y = position_df['y'].values

# Plot arena with 3D extrusion
perform_plot_flat_arena(
    p, x, y,
    z=-0.01,
    smoothing=True,
    extrude_height=-5,
    color=[0.1, 0.1, 0.1],
    pbr=True,
    metallic=0.8,
    roughness=0.5
)

p.show()
```

## Complete Example

```python
import pyvista as pv
import pandas as pd
from pyphoplacecellanalysis.Pho3D.PyVista.spikeAndPositions import (
    perform_plot_flat_arena,
    build_active_spikes_plot_data_df,
    spike_geom_cone
)
from pyphoplacecellanalysis.Pho3D.PyVista.gui import (
    customize_default_pyvista_theme
)

# Apply theme
customize_default_pyvista_theme()

# Create plotter
p = pv.Plotter()

# Plot arena
perform_plot_flat_arena(
    p,
    position_x,
    position_y,
    smoothing=True,
    extrude_height=-5
)

# Prepare spike data
spike_df = pd.DataFrame({
    'x': spike_x,
    'y': spike_y,
    'aclu': cell_ids,
    'R': red,
    'G': green,
    'B': blue,
    'render_opacity': np.ones(len(spike_x))
})

# Add spikes
spike_pdata, spike_pc = build_active_spikes_plot_data_df(
    spike_df,
    spike_geom_cone
)

p.add_mesh(
    spike_pc,
    scalars='rgb',
    rgb=True,
    name='spikes'
)

# Set camera
p.camera_position = 'xy'

# Show
p.show()
```

## Best Practices

<AccordionGroup>
  <Accordion title="Performance">
    - Use `scale=False` in glyph rendering when all glyphs are same size
    - Pre-compute RGBA colors in dataframe
    - Use appropriate geometry complexity for spike glyphs
    - Enable `pbr=True` for better visual quality
  </Accordion>
  
  <Accordion title="Visual Quality">
    - Use physically-based rendering (PBR) for realistic lighting
    - Apply anti-aliasing: `p.enable_anti_aliasing()`
    - Choose appropriate background colors
    - Use extrusion for better depth perception
  </Accordion>
  
  <Accordion title="Interactivity">
    - Add keyboard callbacks for custom interactions
    - Use mutually exclusive checkboxes for layer comparison
    - Implement time-slider for temporal navigation
    - Display helper text for user guidance
  </Accordion>
</AccordionGroup>

<Warning>
  The `smoothing=True` option uses Delaunay triangulation which may not work correctly for non-convex maze shapes. Disable smoothing for complex arena geometries.
</Warning>
