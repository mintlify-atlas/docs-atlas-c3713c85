## Overview

The decoder module provides implementations of Bayesian position decoders for analyzing spatial coding in place cells. These decoders reconstruct position from spike activity using placefield information.

## BasePositionDecoder

Stateless base decoder class that stores only the raw inputs needed for decoding.

```python
from pyphoplacecellanalysis.Analysis.Decoder.reconstruction import BasePositionDecoder

decoder = BasePositionDecoder(pf=pf1D, debug_print=False)
```

<ParamField path="pf" type="PfND" required>
  Place field object containing tuning curves and ratemap information
</ParamField>

<ParamField path="neuron_IDXs" type="np.ndarray">
  Indices of neurons included in the decoder (computed from pf if not provided)
</ParamField>

<ParamField path="neuron_IDs" type="np.ndarray">
  Cell IDs (aclus) of neurons included in the decoder
</ParamField>

### Properties

<ResponseField name="time_bin_size" type="float">
  Size of decoding time bins in seconds
</ResponseField>

<ResponseField name="num_time_windows" type="int">
  Number of time windows that have been decoded
</ResponseField>

<ResponseField name="original_position_data_shape" type="tuple">
  Shape of the original position data (n_xbins, n_ybins) or (n_xbins,) for 1D
</ResponseField>

### Methods

#### decode_specific_epochs

Decode neural activity during specific time epochs.

```python
decoded_result = decoder.decode_specific_epochs(
    spikes_df=spikes_df,
    filter_epochs=replay_epochs,
    decoding_time_bin_size=0.025,
    debug_print=False
)
```

<ParamField path="spikes_df" type="pd.DataFrame" required>
  Spike dataframe with columns ['t', 'aclu', 'shank', ...]
</ParamField>

<ParamField path="filter_epochs" type="pd.DataFrame | Epoch" required>
  Time epochs to decode, with 'start' and 'stop' times
</ParamField>

<ParamField path="decoding_time_bin_size" type="float" default="0.025">
  Time bin size for decoding in seconds
</ParamField>

<ParamField path="use_single_time_bin_per_epoch" type="bool" default="False">
  If True, decode each epoch as a single time bin
</ParamField>

<ResponseField name="result" type="DecodedFilterEpochsResult">
  Container with decoded posteriors and most likely positions for each epoch
</ResponseField>

#### get_by_id

Create a subset decoder with only specified neurons.

```python
subset_decoder = decoder.get_by_id(
    ids=[1, 2, 5, 10],
    defer_compute_all=False
)
```

<ParamField path="ids" type="list | np.ndarray" required>
  Neuron IDs (aclus) to include in subset decoder
</ParamField>

<ParamField path="defer_compute_all" type="bool" default="False">
  If True, skip recomputation of decoder parameters (useful when building many subset decoders)
</ParamField>

<ResponseField name="subset_decoder" type="BasePositionDecoder">
  New decoder containing only the specified neurons
</ResponseField>

## Example Usage

### Basic 1D Decoding

```python
from pyphoplacecellanalysis.Analysis.Decoder.reconstruction import BasePositionDecoder
from neuropy.analyses.placefields import PfND

# Build 1D place fields
pf1D = PfND(spikes_df, position.linear_pos_obj)

# Create decoder
decoder = BasePositionDecoder(pf=pf1D, debug_print=False)

# Decode replay epochs
result = decoder.decode_specific_epochs(
    spikes_df=spikes_df,
    filter_epochs=replay_epochs,
    decoding_time_bin_size=0.025
)

# Access decoded positions
for epoch_idx in range(result.num_filter_epochs):
    posterior = result.p_x_given_n_list[epoch_idx]  # (n_xbins, n_tbins)
    positions = result.most_likely_positions_list[epoch_idx]  # (n_tbins,)
    print(f"Epoch {epoch_idx}: {len(positions)} time bins decoded")
```

### Leave-One-Out Analysis

```python
# Create decoders with each neuron left out
neuron_ids = decoder.neuron_IDs
left_out_decoders = {}

for aclu in neuron_ids:
    # Get all neurons except the current one
    subset_ids = [id for id in neuron_ids if id != aclu]
    left_out_decoders[aclu] = decoder.get_by_id(
        subset_ids,
        defer_compute_all=True
    )

# Decode with each left-out decoder
for aclu, left_out_decoder in left_out_decoders.items():
    result = left_out_decoder.decode_specific_epochs(
        spikes_df=spikes_df[spikes_df['aclu'] != aclu],
        filter_epochs=epochs,
        decoding_time_bin_size=0.025
    )
    # Analyze contribution of left-out neuron
    print(f"Decoder without neuron {aclu}: {result.num_filter_epochs} epochs")
```

### Continuous Session Decoding

```python
from neuropy.core.epoch import Epoch

# Create single epoch spanning entire session
session_duration = spikes_df['t'].max() - spikes_df['t'].min()
session_epoch = Epoch([
    [spikes_df['t'].min(), spikes_df['t'].max()]
])

# Decode entire session
continuous_result = decoder.decode_specific_epochs(
    spikes_df=spikes_df,
    filter_epochs=session_epoch,
    decoding_time_bin_size=0.025
)

# Get single continuous posterior
posterior = continuous_result.p_x_given_n_list[0]  # (n_xbins, n_session_tbins)
time_centers = continuous_result.time_window_centers[0]
print(f"Decoded {len(time_centers)} time bins over {session_duration:.1f}s")
```

## BayesianPlacemapPositionDecoder

Extended decoder class that holds decoded results and provides additional functionality for continuous decoding and result analysis.

```python
from pyphoplacecellanalysis.Analysis.Decoder.reconstruction import BayesianPlacemapPositionDecoder

# Create decoder with time binning
decoder = BayesianPlacemapPositionDecoder(
    pf=pf1D,
    spikes_df=spikes_df,
    time_bin_size=0.025,
    setup_on_init=True
)
```

<ParamField path="pf" type="PfND" required>
  Place field object containing tuning curves for decoding
</ParamField>

<ParamField path="spikes_df" type="pd.DataFrame" required>
  DataFrame containing spike times and neuron IDs
</ParamField>

<ParamField path="time_bin_size" type="float" required>
  Size of decoding time bins in seconds (e.g., 0.025 for 25ms bins)
</ParamField>

<ParamField path="setup_on_init" type="bool" default="True">
  Whether to compute time binning on initialization
</ParamField>

<ParamField path="debug_print" type="bool" default="False">
  Enable debug output during decoding
</ParamField>

### Differences from BasePositionDecoder

`BayesianPlacemapPositionDecoder` extends `BasePositionDecoder` with:

- **Time binning**: Pre-computes spike counts in time bins
- **Result storage**: Stores decoded posterior probabilities and positions
- **Continuous decoding**: Designed for decoding entire sessions
- **Marginal distributions**: Computes marginal position probabilities

<Note>
`BasePositionDecoder` is stateless and suitable for epoch-specific decoding, while `BayesianPlacemapPositionDecoder` is stateful and optimized for continuous session decoding.
</Note>

### Additional Properties

<ResponseField name="time_window_edges" type="np.ndarray">
  Edges of time windows used for binning
</ResponseField>

<ResponseField name="time_window_centers" type="np.ndarray">
  Center timestamps of each time window
</ResponseField>

<ResponseField name="unit_specific_time_binned_spike_counts" type="np.ndarray">
  Spike counts per neuron per time bin (n_neurons, n_time_bins)
</ResponseField>

<ResponseField name="p_x_given_n" type="np.ndarray">
  Posterior probability of position given spikes (n_xbins, n_time_bins)
</ResponseField>

<ResponseField name="most_likely_positions" type="np.ndarray">
  Most likely position at each time bin
</ResponseField>

<ResponseField name="marginal" type="DynamicContainer">
  Marginal distributions over position dimensions
</ResponseField>

<ResponseField name="is_non_firing_time_bin" type="np.ndarray">
  Boolean array indicating time bins with no spikes
</ResponseField>

### Example: Continuous Session Decoding

```python
from pyphoplacecellanalysis.Analysis.Decoder.reconstruction import BayesianPlacemapPositionDecoder

# Create decoder for entire session
decoder = BayesianPlacemapPositionDecoder(
    pf=pf1D,
    spikes_df=sess.spikes_df,
    time_bin_size=0.025,
    setup_on_init=True
)

# Access pre-computed time binning
print(f"Time bins: {decoder.num_time_windows}")
print(f"Time range: {decoder.time_window_centers[0]:.2f}s - {decoder.time_window_centers[-1]:.2f}s")

# Get spike counts per neuron per time bin
spike_counts = decoder.unit_specific_time_binned_spike_counts
print(f"Spike count matrix shape: {spike_counts.shape}")  # (n_neurons, n_time_bins)

# Compute Bayesian decoding
decoder.compute_all()

# Access results
posterior = decoder.p_x_given_n  # (n_xbins, n_time_bins)
positions = decoder.most_likely_positions  # (n_time_bins,)
print(f"Decoded {len(positions)} positions")
```

### Example: Handling Non-Firing Bins

```python
# Identify time bins with no spikes
no_spike_bins = decoder.is_non_firing_time_bin
print(f"Non-firing bins: {no_spike_bins.sum()} / {len(no_spike_bins)}")

# Filter to only active bins
active_indices = ~no_spike_bins
active_positions = decoder.most_likely_positions[active_indices]
active_times = decoder.time_window_centers[active_indices]

# Use for analysis
print(f"Active decoding bins: {len(active_positions)}")
```

### When to Use Which Decoder

| Use Case | Decoder Class |
|----------|---------------|
| Decode specific replay events | `BasePositionDecoder` |
| Epoch-based analysis | `BasePositionDecoder` |
| Leave-one-out analysis | `BasePositionDecoder` |
| Continuous session decoding | `BayesianPlacemapPositionDecoder` |
| Store decoding results | `BayesianPlacemapPositionDecoder` |
| Pre-compute time binning | `BayesianPlacemapPositionDecoder` |

<Tip>
For most replay and epoch-based analyses, use `BasePositionDecoder.decode_specific_epochs()`. Only use `BayesianPlacemapPositionDecoder` when you need continuous decoding of an entire session or want to store results in the decoder object.
</Tip>
