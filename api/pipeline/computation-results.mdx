## Overview

The `ComputationResult` class stores the output of computations performed on a filtered session. It maintains:

- The input data session
- Computation configuration/parameters used
- Computed output data
- Errors that occurred during computation
- Timing information for each computation

## Fields

### `sess`

<ParamField path="sess" type="DataSession" required>
  The data session this computation was performed on (typically a filtered session)
</ParamField>

### `computation_config`

<ParamField path="computation_config" type="DynamicParameters" optional>
  Configuration parameters used for the computation (e.g., PlacefieldComputationParameters)
</ParamField>

### `computed_data`

<ParamField path="computed_data" type="DynamicParameters" optional>
  Dictionary-like container storing all computed results, keyed by computation name
</ParamField>

### `accumulated_errors`

<ParamField path="accumulated_errors" type="DynamicParameters" default="DynamicParameters()">
  Dictionary of exceptions that occurred during computation, keyed by function that failed
</ParamField>

### `computation_times`

<ParamField path="computation_times" type="DynamicParameters" default="DynamicParameters()">
  Dictionary of completion timestamps for each computation function
</ParamField>

```python
from pyphoplacecellanalysis.General.Model.ComputationResults import ComputationResult
```

## Accessing Computed Data

### Accessing Results by Key

```python
# Get computation result for a specific filter
result = curr_pipeline.computation_results['maze1']

# Access specific computed data
pf2D = result.computed_data['pf2D']  # 2D place fields
pf1D = result.computed_data['pf1D']  # 1D place fields
decoder = result.computed_data['pf2D_Decoder']  # Decoder

# List all computed data
print(f"Available data: {list(result.computed_data.keys())}")
```

### Common Computed Data Keys

Filter-specific (non-global) computations:

- `pf1D` - 1D place fields
- `pf2D` - 2D place fields  
- `pf1D_dt` - Time-dependent 1D place fields
- `pf2D_dt` - Time-dependent 2D place fields
- `pf2D_Decoder` - Bayesian decoder
- `extended_stats` - Extended statistics
- `firing_rate_trends` - Firing rate analysis
- `velocity_vs_pf_simplified_count_density` - Velocity vs position analysis

Global computations (in `global_computation_results`):

- `long_short_fr_indicies_analysis` - Long/short track firing rate indices
- `long_short_post_decoding` - Post-decoding analysis
- `jonathan_firing_rate_analysis` - Jonathan's firing rate analysis
- `merged_directional_placefields` - Directional place fields
- `long_short_decoding_analyses` - Decoding comparisons
- `directional_decoders_decode_continuous` - Continuous directional decoding

### Example: Accessing Place Fields

```python
# Get place field computation results
result = curr_pipeline.computation_results['maze1']
```

## Error Handling

### Checking for Errors

```python
result = curr_pipeline.computation_results['maze1']

# Check if any errors occurred
if len(result.accumulated_errors) > 0:
    print(f"Found {len(result.accumulated_errors)} errors")
    
    # Iterate through errors
    for failed_function, exception in result.accumulated_errors.items():
        print(f"\nFunction: {failed_function.__name__}")
        print(f"Error: {exception}")
        print(f"Exception type: {type(exception.e)}")
        print(f"Traceback: {exception.exception_info}")
```

### Clearing Errors

```python
# Clear accumulated errors after fixing issues
result.accumulated_errors.clear()

# Or clear all errors across all filters
for filter_name, result in curr_pipeline.computation_results.items():
    result.accumulated_errors.clear()
```

## Timing Information

### Accessing Computation Times

```python
from datetime import datetime

result = curr_pipeline.computation_results['maze1']

# Get completion times for each computation
for fn_name, completion_time in result.computation_times.items():
    print(f"{fn_name}: completed at {completion_time}")

# Find most recent computation
if len(result.computation_times) > 0:
    latest_time = max(result.computation_times.values())
    print(f"Most recent computation: {latest_time}")
    
    # Time since last computation
    time_delta = datetime.now() - latest_time
    print(f"Time since last computation: {time_delta}")
```

### Example: Pipeline-wide Timing

```python
# Get timing info across all filters and global computations
latest_time, epoch_times, detailed_times, global_times = \
    curr_pipeline.stage.get_computation_times()

print(f"Latest computation anywhere: {latest_time}")

print("\nPer-filter latest times:")
for filter_name, time in epoch_times.items():
    print(f"  {filter_name}: {time}")

print("\nDetailed computation times:")
for filter_name, times_dict in detailed_times.items():
    print(f"  {filter_name}:")
    for fn_name, time in times_dict.items():
        print(f"    {fn_name}: {time}")
```

## Complete Example

```python
from pyphoplacecellanalysis.General.Pipeline.NeuropyPipeline import NeuropyPipeline
from datetime import datetime
import pandas as pd

# Load pipeline with computed results
curr_pipeline = NeuropyPipeline.try_init_from_saved_pickle_or_reload_if_needed(
    type_name='kdiba',
    known_type_properties=known_data_session_type_dict['kdiba']
)

# Iterate through all filter results
for filter_name, result in curr_pipeline.computation_results.items():
    print(f"\n{'='*60}")
    print(f"Filter: {filter_name}")
    print(f"{'='*60}")
    
    # Show session info
    print(f"Session: {result.sess.name}")
    print(f"Duration: {result.sess.duration:.2f} seconds")
    print(f"Neurons: {result.sess.n_neurons}")
    
    # Show configuration
    config = result.computation_config
    if config is not None:
        print(f"\nConfiguration:")
        print(f"  Speed threshold: {config.pf_params.speed_thresh}")
        print(f"  Grid bin: {config.pf_params.grid_bin}")
        print(f"  FR threshold: {config.pf_params.frate_thresh}")
    
    # Show computed data
    print(f"\nComputed data ({len(result.computed_data)} items):")
    for key in result.computed_data.keys():
        print(f"  - {key}")
    
    # Show errors if any
    if len(result.accumulated_errors) > 0:
        print(f"\nErrors ({len(result.accumulated_errors)}):")
        for fn, error in result.accumulated_errors.items():
            print(f"  - {fn.__name__}: {error.e}")
    else:
        print(f"\nNo errors!")
    
    # Show timing
    if len(result.computation_times) > 0:
        latest = max(result.computation_times.values())
        print(f"\nLatest computation: {latest}")
        delta = datetime.now() - latest
        print(f"Time since: {delta}")

# Check global results
print(f"\n\n{'='*60}")
print(f"Global Computations")
print(f"{'='*60}")

global_result = curr_pipeline.global_computation_results
print(f"\nGlobal computed data ({len(global_result.computed_data)} items):")
for key in global_result.computed_data.keys():
    print(f"  - {key}")

if len(global_result.accumulated_errors) > 0:
    print(f"\nGlobal errors ({len(global_result.accumulated_errors)}):")
    for fn, error in global_result.accumulated_errors.items():
        print(f"  - {fn.__name__}: {error.e}")

# Access specific global data
if 'long_short_fr_indicies_analysis' in global_result.computed_data:
    fr_analysis = global_result.computed_data['long_short_fr_indicies_analysis']
    x_frs = fr_analysis['x_frs_index']
    y_frs = fr_analysis['y_frs_index']
    
    # Create DataFrame for analysis
    fr_df = pd.DataFrame({
        'aclu': list(x_frs.keys()),
        'long_fr_idx': list(x_frs.values()),
        'short_fr_idx': list(y_frs.values())
    })
    
    print(f"\nFiring Rate Indices Summary:")
    print(fr_df.describe())
```
