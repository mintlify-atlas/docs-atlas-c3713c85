## Overview

The `NeuropyPipeline` class is the central component for managing place cell analysis workflows. It orchestrates data loading, filtering, computation, and visualization stages.

## Class Definition

```python
    PipelineWithDisplayPipelineStageMixin,
    PipelineWithDisplaySavingMixin,
    HDF_SerializationMixin
)
```

```python
from pyphoplacecellanalysis.General.Pipeline.NeuropyPipeline import NeuropyPipeline
```

```python
    force_reload=False,  # Use cached pickle if available
```

### `perform_computations`

Execute registered computation functions on filtered sessions.

<ParamField path="active_computation_params" type="DynamicParameters" optional>
  Computation parameters to use (if None, uses existing configs)
</ParamField>

<ParamField path="enabled_filter_names" type="List[str]" optional>
  List of filter names to compute (if None, computes all)
</ParamField>

<ParamField path="overwrite_extant_results" type="bool" default="False">
  If True, recompute even if results already exist
</ParamField>

<ParamField path="computation_functions_name_includelist" type="List[str]" optional>
  Only run these specific computation functions
</ParamField>

<ParamField path="computation_functions_name_excludelist" type="List[str]" optional>
  Exclude these computation functions from execution
</ParamField>

<ParamField path="fail_on_exception" type="bool" default="False">
  If True, raise exceptions; if False, accumulate errors and continue
</ParamField>

<ParamField path="debug_print" type="bool" default="False">
  Print debug information
</ParamField>

### Example

```python
# Perform all registered computations
curr_pipeline.perform_computations()

# Perform only specific computations
curr_pipeline.perform_computations(
    computation_functions_name_includelist=['pf_computation', 'extended_stats'],
    fail_on_exception=False
)

# Access computation results
for filter_name, result in curr_pipeline.computation_results.items():
    print(f"Filter: {filter_name}")
    print(f"Computed data: {result.computed_data.keys()}")
```

## Complete Example

```python
from pyphoplacecellanalysis.General.Pipeline.NeuropyPipeline import (
    NeuropyPipeline, 
    PipelineSavingScheme
)
from neuropy.core.session.KnownDataSessionTypeProperties import KnownDataSessionTypeProperties
from pathlib import Path

# Get known session types
known_data_session_type_dict = KnownDataSessionTypeProperties.get_registry()

# Initialize pipeline (try loading from pickle first)
curr_pipeline = NeuropyPipeline.try_init_from_saved_pickle_or_reload_if_needed(
    type_name='kdiba',
    known_type_properties=known_data_session_type_dict['kdiba'],
    override_basepath=Path('/data/kdiba/gor01/one/2006-6-08_14-26-15'),
    force_reload=False
)

# Filter sessions
active_session_filter_configurations = {
    'maze1': DynamicContainer({'epoch_name': 'maze1'}),
    'maze2': DynamicContainer({'epoch_name': 'maze2'}),
    'maze': DynamicContainer({'epoch_name': 'maze'})
}
curr_pipeline.filter_sessions(active_session_filter_configurations)

# Perform computations
curr_pipeline.perform_computations(
    overwrite_extant_results=False,
    fail_on_exception=False
)

# Access results
for filter_name in ['maze1', 'maze2', 'maze']:
    result = curr_pipeline.computation_results[filter_name]
    print(f"\n{filter_name} results:")
    print(f"  Computed: {list(result.computed_data.keys())}")
    print(f"  Errors: {len(result.accumulated_errors)}")

# Access global results
global_result = curr_pipeline.global_computation_results
print(f"\nGlobal computations: {list(global_result.computed_data.keys())}")

# Save pipeline
saved_path = curr_pipeline.save_pipeline(
    saving_mode=PipelineSavingScheme.TEMP_THEN_OVERWRITE
)
print(f"\nPipeline saved to: {saved_path}")

# Export to HDF5
h5_path, error = curr_pipeline.export_pipeline_to_h5()
if error is None:
    print(f"HDF5 export successful: {h5_path}")
```
