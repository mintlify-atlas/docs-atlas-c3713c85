## Overview

The `ComputedPipelineStage` class manages the computation stage of the pipeline. It handles:

- Registration and execution of computation functions
- Managing computation results and errors
- Supporting both filter-specific and global computations
- Tracking computation dependencies and execution order

## Computation Function Registration

### `register_computation`

Register a computation function for later execution.

<ParamField path="registered_name" type="str" required>
  Name to register the function under
</ParamField>

<ParamField path="computation_function" type="Callable" required>
  The computation function to register
</ParamField>

<ParamField path="is_global" type="bool" required>
  True if this is a global computation (operates across filters), False for filter-specific
</ParamField>

### Example

```python
def my_computation(computation_result, **kwargs):
    """Custom computation function."""
    # Access previous results
    previous_data = computation_result.computed_data
    
    # Perform computation
    new_result = perform_analysis(computation_result.sess)
    
    # Store result
    computation_result.computed_data['my_analysis'] = new_result
    
    return computation_result

# Register the function
stage.register_computation(
    registered_name='my_analysis',
    computation_function=my_computation,
    is_global=False
)
```

## Computation Execution

### `perform_computations`

Execute all registered computation functions.

<ParamField path="active_computation_params" type="DynamicParameters" optional>
  Parameters to use for computations
</ParamField>

<ParamField path="enabled_filter_names" type="List[str]" optional>
  Filter names to compute (None = all filters)
</ParamField>

<ParamField path="overwrite_extant_results" type="bool" default="False">
  Recompute even if results exist
</ParamField>

<ParamField path="computation_functions_name_includelist" type="List[str]" optional>
  Only run these specific functions
</ParamField>

<ParamField path="computation_functions_name_excludelist" type="List[str]" optional>
  Exclude these functions
</ParamField>

<ParamField path="fail_on_exception" type="bool" default="False">
  Raise exceptions vs. accumulate errors
</ParamField>

<ParamField path="debug_print" type="bool" default="False">
  Print debug information
</ParamField>

### Example

```python
# Perform all computations
stage.perform_computations(
    overwrite_extant_results=False,
    fail_on_exception=False
)

# Perform specific computations only
stage.perform_computations(
    computation_functions_name_includelist=['pf2D', 'pf2D_Decoder'],
    overwrite_extant_results=True
)
```

### Example

```python

# Get computation timing info
latest_time, epoch_times, detailed_times, (global_time, global_details) = \
    stage.get_computation_times()
```

## Complete Example

```python
from pyphoplacecellanalysis.General.Pipeline.Stages.Computation import (
    ComputedPipelineStage,
    FunctionsSearchMode
)
from pyphoplacecellanalysis.General.Pipeline.Stages.Loading import LoadedPipelineStage
from datetime import datetime

# Create computation stage from loaded stage
loaded_stage = LoadedPipelineStage(...)
stage = ComputedPipelineStage.init_from_previous_stage(loaded_stage)

# Register custom computation
def custom_analysis(computation_result, threshold=0.5, **kwargs):
    """Custom analysis computation."""
    sess = computation_result.sess
    
    # Perform analysis
    result_data = analyze_session(sess, threshold=threshold)
    
    # Store in computed_data
    computation_result.computed_data['custom_analysis'] = result_data
    
    return computation_result

stage.register_computation(
    registered_name='custom_analysis',
    computation_function=custom_analysis,
    is_global=False
)

# Perform computations
stage.perform_computations(
    computation_functions_name_includelist=['pf_computation', 'custom_analysis'],
    fail_on_exception=False
)

# Check results
for filter_name, result in stage.computation_results.items():
    print(f"\n=== {filter_name} ===")
    print(f"Computed: {list(result.computed_data.keys())}")
    
    if len(result.accumulated_errors) > 0:
        print(f"Errors ({len(result.accumulated_errors)}):")
        for fn, error in result.accumulated_errors.items():
            print(f"  - {fn.__name__}: {error}")

# Get computation times
latest, epoch_times, details, global_info = stage.get_computation_times()
print(f"\nLatest computation: {latest}")

# Rerun failed computations after fixing issues
if len(stage.get_failed_computations()) > 0:
    print("\nRetrying failed computations...")
    stage.rerun_failed_computations(fail_on_exception=False)

# Run specific computation with dependencies
stage.resolve_and_execute_full_required_computation_plan(
    computation_functions_name_includelist=['position_decoding'],
    fail_on_exception=False
)
```
