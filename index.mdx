## Quick Example

Get started with a basic analysis pipeline:

```python
from pyphoplacecellanalysis.General.Pipeline.Stages.Loading import loadData
from pyphoplacecellanalysis.General.Pipeline.NeuropyPipeline import NeuropyPipeline

# Load data from your recording session
session = loadData(basepath='/path/to/data')

# Create and run the analysis pipeline
pipeline = NeuropyPipeline.init_from_known_data_session_type(
    basedir='/path/to/data',
    session_name='your_session'
)

# Run computation stages
pipeline.perform_computations()

# Access results
computation_results = pipeline.computation_results
place_fields = computation_results['maze'].computed_data['pf1D']
```
