## Your First Analysis

This guide will walk you through loading a recording session, computing place fields, and decoding position using Bayesian reconstruction.

<Note>
  This quickstart assumes you have already [installed pyPhoPlaceCellAnalysis](/installation) and have access to neural recording data in a supported format (Klustakwik, Phy, Neuroscope, etc.).
</Note>

## Pipeline Overview

The analysis workflow follows four stages:

```mermaid
graph LR
    A[Load Data] --> B[Filter Sessions]
    B --> C[Compute Results]
    C --> D[Visualize & Export]
```

Let's walk through each stage.

## Step 1: Import Libraries

First, import the necessary modules:

```python
from pathlib import Path
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# Core pipeline
from pyphoplacecellanalysis.General.Pipeline.NeuropyPipeline import NeuropyPipeline
from neuropy.core.session.Formats.BaseDataSessionFormats import DataSessionFormatRegistryHolder

# For batch processing
from pyphoplacecellanalysis.General.Batch.NonInteractiveProcessing import batch_load_session
from pyphoplacecellanalysis.General.Pipeline.NeuropyPipeline import PipelineSavingScheme
```

## Step 2: Load Your Session

Load a recording session using the pipeline. The pipeline supports automatic detection of data formats:

<CodeGroup>
```python From Known Data Type
# Define your data path
basedir = Path('/path/to/your/data/session_folder')

# Get known data session types
known_data_session_type_dict = DataSessionFormatRegistryHolder.get_registry_known_data_session_type_dict()

# Initialize pipeline for a specific data type (e.g., 'kdiba' format)
pipeline = NeuropyPipeline.init_from_known_data_session_type(
    type_name='kdiba',
    known_type_properties=known_data_session_type_dict['kdiba'],
    override_basepath=basedir
)

print(f"Loaded session: {pipeline.session_name}")
```

```python With Pickle Caching
# For faster reloading, use pickle caching
# First load will be slow, subsequent loads are instant
pipeline = NeuropyPipeline.try_init_from_saved_pickle_or_reload_if_needed(
    type_name='kdiba',
    known_type_properties=known_data_session_type_dict['kdiba'],
    override_basepath=basedir,
    force_reload=False,  # Set True to force reload from raw data
    active_pickle_filename='loadedSessPickle.pkl'
)

print(f"Pipeline loaded from {'cache' if pipeline.has_associated_pickle else 'raw data'}")
```

```python Using Batch Loader
# For production workflows, use the batch loader
from pyphoplacecellanalysis.General.Batch.NonInteractiveProcessing import batch_load_session

pipeline = batch_load_session(
    global_data_root_parent_path=Path('/path/to/data/root'),
    active_data_mode_name='kdiba',
    basedir=basedir,
    active_pickle_filename='loadedSessPickle.pkl',
    force_reload=False,
    saving_mode=PipelineSavingScheme.TEMP_THEN_OVERWRITE
)
```
</CodeGroup>

## Step 3: Filter Sessions

Filter the session by epochs (maze running, sleep) and neuron types:

```python
# Filter for pyramidal neurons during maze epochs
active_session_filter_configurations = pipeline.sess.build_default_filter_functions(
    epoch_name_includelist=['maze1', 'maze2', 'maze']
)

# Apply filters
pipeline.filter_sessions(
    active_session_filter_configurations=active_session_filter_configurations
)

# Access filtered sessions
filtered_session_names = pipeline.filtered_session_names
print(f"Filtered sessions: {filtered_session_names}")

# Get a specific filtered session
maze1_session = pipeline.filtered_sessions['maze1']
print(f"Maze1 has {len(maze1_session.neurons)} neurons")
print(f"Duration: {maze1_session.duration:.1f} seconds")
```

## Step 4: Compute Place Fields and Decode Position

Run the computation pipeline to calculate place fields and perform Bayesian decoding:

```python
# Perform all registered computations
pipeline.perform_computations()

# Access computed results for a specific epoch
maze1_results = pipeline.computation_results['maze1'].computed_data

# Get 1D place fields
pf1D = maze1_results.get('pf1D')
print(f"1D place fields computed for {pf1D.ratemap.n_neurons} neurons")
print(f"Position bins: {pf1D.ratemap.xbin_labels.shape}")

# Get 2D place fields if available
if 'pf2D' in maze1_results:
    pf2D = maze1_results['pf2D']
    print(f"2D place fields: {pf2D.ratemap.xbin_labels.shape} x {pf2D.ratemap.ybin_labels.shape}")
```

### Bayesian Position Decoding

Decode the animal's position from neural activity:

```python
from pyphoplacecellanalysis.Analysis.Decoder.reconstruction import BayesianPlacemapPositionDecoder

# Create a decoder from place fields
decoder = BayesianPlacemapPositionDecoder(
    pf=pf2D,
    time_bin_size=0.02  # 20ms time bins
)

print(f"Decoder initialized with {decoder.pf.ratemap.n_neurons} neurons")
print(f"Spatial bins: {decoder.xbin.shape}")

# Decode position for a specific epoch
epoch_to_decode = maze1_session.epochs.get_named_timerange('maze1')
decoded_result = decoder.decode_specific_epochs(
    spikes_df=maze1_session.spikes_df,
    filter_epochs=epoch_to_decode,
    decoding_time_bin_size=0.02
)

print(f"Decoded {decoded_result.nbins} time bins")
print(f"Posterior shape: {decoded_result.p_x_given_n.shape}")
```

Visualize the decoded positions and place fields:

## Step 6: Save Your Results

Save the pipeline and results for later use:

```python
# Save the entire pipeline (includes all computations)
pipeline.save_pipeline(
    saving_mode=PipelineSavingScheme.TEMP_THEN_OVERWRITE,
    active_pickle_filename='my_analysis_pipeline.pkl'
)

# Save specific computation results
pipeline.save_global_computation_results(
    override_global_pickle_filename='global_computations.pkl'
)

# Export to HDF5 format for larger datasets
hdf5_path, error = pipeline.export_pipeline_to_h5(
    override_filename='my_analysis.h5'
)

if error is None:
    print(f"Pipeline exported to {hdf5_path}")
else:
    print(f"Export error: {error}")
```

## Complete Example

Here's a complete script that runs the full analysis:

```python complete_analysis.py
from pathlib import Path
import matplotlib.pyplot as plt
from pyphoplacecellanalysis.General.Pipeline.NeuropyPipeline import NeuropyPipeline, PipelineSavingScheme
from neuropy.core.session.Formats.BaseDataSessionFormats import DataSessionFormatRegistryHolder
from pyphoplacecellanalysis.Analysis.Decoder.reconstruction import BayesianPlacemapPositionDecoder

def run_analysis(data_path: Path):
    """Run complete place cell analysis pipeline."""
    
    # 1. Load session
    print("Loading session...")
    known_types = DataSessionFormatRegistryHolder.get_registry_known_data_session_type_dict()
    pipeline = NeuropyPipeline.try_init_from_saved_pickle_or_reload_if_needed(
        type_name='kdiba',
        known_type_properties=known_types['kdiba'],
        override_basepath=data_path,
        active_pickle_filename='loadedSessPickle.pkl'
    )
    
    # 2. Filter sessions
    print("Filtering sessions...")
    filters = pipeline.sess.build_default_filter_functions(
        epoch_name_includelist=['maze1', 'maze2']
    )
    pipeline.filter_sessions(active_session_filter_configurations=filters)
    
    # 3. Compute place fields
    print("Computing place fields...")
    pipeline.perform_computations()
    
    # 4. Get results
    maze1_results = pipeline.computation_results['maze1'].computed_data
    pf2D = maze1_results['pf2D']
    
    # 5. Decode position
    print("Decoding position...")
    decoder = BayesianPlacemapPositionDecoder(pf=pf2D, time_bin_size=0.02)
    epoch = pipeline.filtered_sessions['maze1'].epochs.get_named_timerange('maze1')
    decoded = decoder.decode_specific_epochs(
        spikes_df=pipeline.filtered_sessions['maze1'].spikes_df,
        filter_epochs=epoch,
        decoding_time_bin_size=0.02
    )
    
    # 6. Save results
    print("Saving results...")
    pipeline.save_pipeline(
        saving_mode=PipelineSavingScheme.TEMP_THEN_OVERWRITE,
        active_pickle_filename='complete_analysis.pkl'
    )
    
    print(f"Analysis complete!")
    print(f"  Neurons: {len(pf2D.ratemap.neuron_ids)}")
    print(f"  Decoded bins: {decoded.nbins}")
    print(f"  Decoding accuracy: {decoded.most_likely_positions.shape}")
    
    return pipeline, decoder, decoded

if __name__ == '__main__':
    data_path = Path('/path/to/your/session')
    pipeline, decoder, decoded_result = run_analysis(data_path)
```

## Working with Global Computations

Access cross-session and global analysis results:

```python
# Access global computation results
global_results = pipeline.global_computation_results.computed_data

# Example: Access directional placefield computations
if 'DirectionalPlacefields' in global_results:
    directional_pf = global_results['DirectionalPlacefields']
    print(f"Directional analysis available: {directional_pf.keys()}")

# Access long/short track decoders
if 'long_short_decoding' in global_results:
    decoders = global_results['long_short_decoding']
    long_decoder = decoders.long_decoder
    short_decoder = decoders.short_decoder
    print(f"Long track: {long_decoder.pf.ratemap.n_neurons} neurons")
    print(f"Short track: {short_decoder.pf.ratemap.n_neurons} neurons")
```

## Tips and Best Practices

<AccordionGroup>
  <Accordion title="Use pickle caching for faster iteration">
    After the initial load, the pipeline saves to a pickle file. Set `force_reload=False` to use the cache:
    
    ```python
    pipeline = NeuropyPipeline.try_init_from_saved_pickle_or_reload_if_needed(
        ...,
        force_reload=False  # Fast subsequent loads
    )
    ```
  </Accordion>
  
  <Accordion title="Filter neurons before computing place fields">
    Filtering out interneurons and low-quality units improves place field quality:
    
    ```python
    # Default filters include pyramidal cell detection
    filters = sess.build_default_filter_functions(
        epoch_name_includelist=['maze1', 'maze2']
    )
    ```
  </Accordion>
  
  <Accordion title="Adjust time bin size for decoding">
    Smaller bins (10-20ms) capture fine temporal structure but have more noise. Larger bins (100-250ms) are more stable:
    
    ```python
    # For trajectory decoding during running
    decoder = BayesianPlacemapPositionDecoder(pf=pf2D, time_bin_size=0.02)
    
    # For replay detection
    decoder = BayesianPlacemapPositionDecoder(pf=pf2D, time_bin_size=0.01)
    ```
  </Accordion>
  
  <Accordion title="Check computation completion">
    Verify all computations completed successfully:
    
    ```python
    # Check which computations are available
    print(pipeline.computation_results['maze1'].computed_data.keys())
    
    # Check for errors
    if hasattr(pipeline, 'computation_errors'):
        print(f"Errors: {pipeline.computation_errors}")
    ```
  </Accordion>
</AccordionGroup>
